# S3 veri kaynakları

- Bucket ve iki izinli object key yalnızca deployment sırasında güvenli
  parametreler olarak sağlanır; bu repoda tutulmaz.
- Desteklenen tür: `.xlsx`
- Yanıt dili: Kullanıcının dili

Lambda yalnızca deployment sırasında verilen iki tam nesne anahtarını okur.
Aynı konuma sonradan eklenen başka nesneler otomatik olarak kapsamda değildir.

Gizli anahtar, parola veya oturum belirteci bu depoya yazılmaz.
